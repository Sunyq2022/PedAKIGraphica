ICU measurement and transportability

A public reproducibility companion for a three-system adult ICU study of semantic representation, physiological-state availability and source-extraction quality.

Children’s Health Data Science Team

Research release README Analysis code Figure assets
Public release boundary: patient-level records, raw MIMIC/eICU files, prediction files, restricted local paths and hospital-level observability detail are not included. Results are predictive transport analyses only—not causal effects, treatment-policy values, clinical utility, clinical validation or deployment evidence.
